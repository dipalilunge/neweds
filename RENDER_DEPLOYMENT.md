# Engineering Design Studio - Render deployment

## Render settings

This project includes a `render.yaml` Blueprint configuration. Admissions and service enquiries can be stored in Supabase; the Google Sheets integration remains available when Supabase is not configured.

### Supabase setup (recommended)

1. In the Supabase project, open **SQL Editor**, paste the contents of [`supabase_schema.sql`](./supabase_schema.sql), and run it. This creates the admissions and service-enquiries tables with row-level security enabled.
2. In Supabase, open **Project Settings -> API** and copy the project URL and the `service_role` secret key. Keep the key private; never put it in browser code or commit it to GitHub.
3. In Render, open the web service -> **Environment** and set `SUPABASE_URL` to the project URL and `SUPABASE_SERVICE_ROLE_KEY` to the `service_role` secret.
4. Set strong values for `EDS_ADMIN_PASSWORD` and `EDS_STUDENT_PASSWORD`. `EDS_SECRET_KEY` is generated by the Blueprint.
5. Deploy or trigger a manual deploy. When both Supabase variables are set, admissions and service enquiries use Supabase instead of Sheets or local CSV.

## Render environment variables

- `SUPABASE_URL` = Supabase project URL
- `SUPABASE_SERVICE_ROLE_KEY` = Supabase `service_role` secret; enter as a secret
- `EDS_ADMIN_PASSWORD` and `EDS_STUDENT_PASSWORD` = strong passwords

The Google Sheets variables and `EDS_GOOGLE_CREDENTIALS_JSON` are not needed for admissions/enquiries when Supabase is configured.

## Verify after deployment

1. Submit a test admission through `/admin` and confirm it appears in the Supabase `admissions` table.
2. Submit a service enquiry and confirm it appears in the Supabase `service_enquiries` table.
3. Check Render logs if a submission fails. With Supabase configured, database errors are returned rather than silently saving to an ephemeral local CSV.

## Other local data

This change moves admissions and service enquiries to Supabase. Student accounts, batches, course-content metadata, student-work metadata/files, reviews, and interview recordings still use local files or memory/Google Drive depending on existing configuration. Render's default filesystem is ephemeral; those features need additional storage integration before their data can be relied on across redeploys.

### Google Sheets alternative

The app also supports Google Sheets for admissions and service enquiries if Supabase is not configured. Configure the `EDS_GOOGLE_CREDENTIALS_JSON` secret with a service-account JSON key and share each configured sheet with that account. Google Sheets does not require these credentials when Supabase is in use.

Do not paste service-account JSON into public chat, source code, or a public Git repository.
